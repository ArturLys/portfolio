# Artur Lys Portfolio

Interactive Minecraft-themed developer portfolio for Artur Lys.

## Highlights
- **Immersive 3D Background**: Features an authentic Three.js rotating panorama background.
- **Minecraft UI**: Custom buttons with pixelated rendering, authentic hover effects, click sounds, and yellow splash texts.
- **Architecture**: Built with Next.js 16, React 19, Tailwind CSS v4, and Three.js for seamless performance.

## Getting Started

### Prerequisites
- Node.js 20+

### Installation

1. **Clone & Install**
   ```bash
   git clone https://github.com/ArturLys/portfolio.git
   cd portfolio
   npm install
   ```

2. **Run the App**
   ```bash
   npm run dev
   ```
   *Open http://localhost:3000 to see the app.*

## Usage
- **Singleplayer**: View my developer projects.
- **Multiplayer**: Get in touch via the contacts page.
- **Advancements**: Explore my achievements and milestones.
- **GitHub**: Link out directly to the source code repository.
